# Local Android Build

Build an installable Android APK locally using Unity's bundled Android SDK and JDK 17. No cloud service or EAS account needed.

## Environment

This machine has a usable Android SDK + JDK bundled with Unity:

| Component | Path |
|-----------|------|
| **JDK 17** (Temurin) | `B:\Unity\6000.2.6f2\Editor\Data\PlaybackEngines\AndroidPlayer\OpenJDK` |
| **Android SDK** | `B:\Unity\6000.2.6f2\Editor\Data\PlaybackEngines\AndroidPlayer\SDK` |
| **Build Tools** | 34.0.0, 36.0.0 |
| **Platforms** | android-33, android-34, android-36 |

**Known conflict:** The system has `ANDROID_SDK_ROOT=E:\AndroidSDK` set globally, which conflicts with `ANDROID_HOME`. This MUST be cleared before building.

## Build Commands

### Release APK (sideloading / testing)

Generate the android project first if it doesn't exist, then build:

```powershell
# Step 1: Generate android project (only needed once, or after expo config changes)
cd B:\Projects\Doiti
npx expo prebuild --platform android --clean

# Step 2: Build the APK
cd B:\Projects\Doiti\android
$env:ANDROID_SDK_ROOT = ''
$env:ANDROID_HOME = 'B:\Unity\6000.2.6f2\Editor\Data\PlaybackEngines\AndroidPlayer\SDK'
$env:JAVA_HOME = 'B:\Unity\6000.2.6f2\Editor\Data\PlaybackEngines\AndroidPlayer\OpenJDK'
.\gradlew.bat assembleRelease "-Dorg.gradle.java.home=B:\Unity\6000.2.6f2\Editor\Data\PlaybackEngines\AndroidPlayer\OpenJDK"
```

**Output:** `B:\Projects\Doiti\android\app\build\outputs\apk\release\app-release.apk`

### Debug APK (auto-signed, easier to install)

```powershell
cd B:\Projects\Doiti\android
$env:ANDROID_SDK_ROOT = ''
$env:ANDROID_HOME = 'B:\Unity\6000.2.6f2\Editor\Data\PlaybackEngines\AndroidPlayer\SDK'
$env:JAVA_HOME = 'B:\Unity\6000.2.6f2\Editor\Data\PlaybackEngines\AndroidPlayer\OpenJDK'
.\gradlew.bat assembleDebug "-Dorg.gradle.java.home=B:\Unity\6000.2.6f2\Editor\Data\PlaybackEngines\AndroidPlayer\OpenJDK"
```

**Output:** `B:\Projects\Doiti\android\app\build\outputs\apk\debug\app-debug.apk`

## How to Execute

When the user asks for a local build, run it via PowerShell to properly handle Windows env vars:

```bash
powershell -Command "cd 'B:\Projects\Doiti\android'; $env:ANDROID_SDK_ROOT = ''; $env:ANDROID_HOME = 'B:\Unity\6000.2.6f2\Editor\Data\PlaybackEngines\AndroidPlayer\SDK'; $env:JAVA_HOME = 'B:\Unity\6000.2.6f2\Editor\Data\PlaybackEngines\AndroidPlayer\OpenJDK'; .\gradlew.bat assembleRelease '-Dorg.gradle.java.home=B:\Unity\6000.2.6f2\Editor\Data\PlaybackEngines\AndroidPlayer\OpenJDK'"
```

Use a **10-minute timeout** (`timeout: 600000`) as the first build takes ~4 minutes and cold builds can take longer.

## Important Notes

- The `android/` directory is in `.gitignore` - it's generated by `npx expo prebuild`
- If you get SDK-related errors, re-run prebuild: `npx expo prebuild --platform android --clean`
- The release APK is unsigned. For Play Store, a signing keystore would be needed
- The debug APK is auto-signed with a debug key and can be directly installed
- Build time: ~3-5 minutes (first build slower due to Gradle daemon startup)
- APK size: ~66 MB

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `ANDROID_HOME` vs `ANDROID_SDK_ROOT` conflict | Make sure `$env:ANDROID_SDK_ROOT = ''` is set |
| Missing build-tools | `& 'B:\Unity\...\SDK\cmdline-tools\latest\bin\sdkmanager.bat' "build-tools;VERSION"` |
| `No such file: gradlew.bat` | Run `npx expo prebuild --platform android` first |
| AAPT2 fails on large images | Convert images to WebP (see commit `7b1b4a7`) |
| Gradle daemon issues | Add `--no-daemon` flag to gradlew command |
