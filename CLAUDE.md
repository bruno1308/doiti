# Doiti - German Grammar Practice App

## Project Overview
Android app built with React Native + Expo to practice German grammar. Three exercise modes:
1. **Der/Die/Das** - Multiple choice article gender quiz
2. **Adjective Endings** - Fill-in-the-blank adjective declension
3. **Case Identification** - Identify grammatical case of each noun phrase in a sentence

## SDS test simulation
Simulates the Swiss SDS (Schweizerischer Digitaler Sprachtest), vor A1 to B2. Rules come from the public Testhandbuch; all items are original.
- `lib/sds/engine.ts` – adaptive rules (100 % → next level; cut score → second task; one writing task per level). The 60 % cut score is our own estimate.
- Modules: only the three forms the real test has (whole test, written = Lesen + Schreiben, oral = Hören + Sprechen; single skills cannot be tested, per the Testreglement), plus a `-quick` variant of each in a quarter of the time (one task per level, one writing task where reading stopped, four-minute interview). The quick variants are our own invention.
- `data/sds/` – Lesen, Hören, Schreiben and Sprechen task banks, Swiss spelling (no ß).
- `components/sds/` – screens; route `app/(tabs)/sds.tsx`.
- Hören plays bundled ElevenLabs recordings (`assets/sds/hoeren/`, generated by `scripts/generate-sds-audio.cjs`; rerun it after changing a script in `data/sds/hoeren.ts`). The device's German voice (`expo-speech`) is only the fallback. The picture tasks (vor A1, A1) follow the Testhandbuch: slow reading, three seconds between lines.
- `lib/sds/voice/` – voice examiner and teacher. `link.ts` is the provider interface: OpenAI Realtime over WebRTC (`openaiLink.ts`, default) or Gemini Live over a WebSocket (`geminiLink.ts`); the server's `VOICE_PROVIDER` decides. Web only for now; native builds show the prompts for solo practice.
- `server/` – separate Vercel project (token minting and AI rating). The only part of the app that needs internet; see `server/README.md`.

## Tech Stack
- **React Native** with **Expo** (managed workflow)
- **TypeScript**
- **Expo Router** for navigation
- **AsyncStorage** for local progress tracking
- **No backend** for practice - offline, all data bundled (exception: the SDS voice examiner and AI rating, see above)

## Project Structure
```

  app/                    # Expo Router screens
    (tabs)/
      index.tsx           # Home screen
      gender.tsx          # Der/Die/Das quiz
      adjectives.tsx      # Adjective endings
      cases.tsx           # Case identification
    _layout.tsx           # Root layout
  components/             # Shared UI components
  data/                   # Bundled TypeScript data files
    nouns.ts              # 303 German nouns with gender, plural, translation

    cases.ts              # 25 annotated case identification sentences
  lib/                    # Utilities and logic
    types.ts              # All TypeScript interfaces and types

    stats.ts              # Progress tracking with AsyncStorage

```

## Design Decisions
- 303 curated common nouns (101 masculine, 102 feminine, 100 neuter)
- Basic progress tracking (total/correct per mode, session history)
- No spaced repetition, no accounts, no internet required
- Immediate feedback on answers (green/red)
